# SkillFlow MVP

SkillFlow MVP — прототип обучающей платформы для создания, модерации и прохождения тестов. Система объединяет веб-интерфейс и полнофункционального Telegram-бота для непрерывного процесса обучения.

Технологический стек:
- **Backend:** FastAPI, SQLAlchemy, Pydantic
- **Frontend:** HTML/CSS/JavaScript (адаптивный интерфейс)
- **Интеграции:** Telegram-бот на aiogram 3.x

## Функциональность

### Управление пользователями
- Регистрация и авторизация (JWT);
- Роли: студент и преподаватель;
- Персистентная привязка Telegram-аккаунта (сохраняется между перезапусками бота).

### Жизненный цикл тестов
- Создание тестов и вопросов (Single Choice, Multiple Choice, Text Answer, Matching);
- Управление статусами через State Machine: `DRAFT -> PENDING_MODERATION -> PUBLISHED`;
- Модерация преподавателем с системой комментариев.

### Прохождение и аналитика
- Прохождение тестов в веб-интерфейсе или **напрямую в Telegram-боте**;
- **Частичное оценивание**: начисление баллов за часть верных ответов в сложных вопросах;
- Автоматическое обновление рейтинга и выдача достижений через EventBus;
- Персональная статистика и глобальные лидерборды.

### Telegram-интеграция
Бот поддерживает:
- `/start` — приветствие и справка;
- `/tests` — каталог опубликованных тестов;
- `/open <id>` — просмотр карточки теста и **запуск прохождения в чате**;
- `/rating` — просмотр таблицы лидеров;
- `/stats` — персональная статистика пользователя;
- `/link <code>` — связка Telegram с веб-аккаунтом.

## Архитектура проекта

```text
app/
  api/           HTTP-маршруты FastAPI
  core/          конфигурация, БД, безопасность, университетский каталог
  models/        SQLAlchemy-сущности (Float scoring)
  repositories/  слой доступа к данным (Repository pattern)
  services/      бизнес-логика: State Machine, Observer, Strategy, Factory, Visitor
  static/        адаптивный frontend
bot/             Telegram-бот (FSM-сценарии прохождения)
```

Вся подробная техническая документация и описание паттернов находятся в файле:
- `SkillFlow Project.docx`

## Запуск локально

### 1) Подготовка окружения

Создайте файл `.env` на основе `.env.example` и заполните `TELEGRAM_BOT_TOKEN`.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2) Старт приложения

```bash
# Запуск бэкенда
uvicorn app.main:app --reload

# Запуск бота (в другом терминале)
python3 -m bot.main
```

После запуска доступны:
- `http://localhost:8000/` — веб-интерфейс;
- `http://localhost:8000/docs` — Swagger/OpenAPI.

## Запуск через Docker Compose

```bash
docker compose up --build
```

Сервисы `app` и `bot` запустятся автоматически.

## Демонстрационный сценарий

1. Зарегистрировать студента.
2. Создать тест в интерфейсе и отправить на модерацию.
3. Войти как преподаватель, одобрить тест.
4. Получить код привязки в профиле.
5. В Telegram-боте выполнить `/link <код>`.
6. Пройти созданный тест прямо в Telegram через команду `/open <id>`.
7. Проверить обновление рейтинга и статистики в вебе или через `/stats`.
